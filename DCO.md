# Developer Certificate of Origin

**Pending counsel review. This page records the intended contribution process
and is not a legal conclusion.**

Contributions to this repository are accepted under the Developer Certificate of
Origin 1.1, the same sign-off the Linux kernel and many other open source
projects use. There is no separate agreement to sign and nothing to send us: you
certify the statement below by adding a `Signed-off-by` line to each commit.

```
Signed-off-by: Your Name <you@example.com>
```

`git commit -s` adds it for you, using the name and email in your git
configuration. Use your real name and an address you can be reached at.
